# 音源曲库与本期选曲范围

## 启用

在现有数据库迁移完成后执行 `supabase-song-catalog.sql`。它会保留已有歌曲和投票，为曲库创建独立表，并撤销旧的自由填写 `submit_song` RPC。用户端随后只能提交曲库中标记为“可用”和“启用”的歌曲。

迁移不会自动添加歌曲。管理员进入运营端的“音源曲库”，录入歌曲名、歌手、音源地址或内部编号、时长和备注。工作人员确认实际音源可在广播设备上播放后，再打开“确认有音源”。

## 本期白名单

默认情况下，用户可以从全部可播歌曲中选择。需要做主题节目或特殊日期节目时，在“音源曲库”中打开“本期白名单”，勾选本期允许投稿的歌曲并保存规则。该规则只影响当前征集期，不删除历史歌曲；关闭开关后恢复使用全部可播歌曲。

白名单依据节目编排和人工审核的歌曲清单，不按创作者的民族、血统或其他个人身份属性自动判断。

## 投稿校验

用户端的下拉选择只负责展示体验，真正的校验在 `submit_song_from_catalog` 数据库函数中完成：

- 曲库条目必须存在；
- 条目必须处于启用且有音源状态；
- 条目必须符合当前征集期白名单；
- 征集期必须正在开放；
- 原有投稿数量和重复投稿规则继续生效。

音源地址只供管理端核对，不由公开曲库接口返回。后续可增加音源巡检任务，将失效条目标记为不可用。
